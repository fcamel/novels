## 動作與傷痕

- 無葉僧出招時坐正、浮空盤腿、雙手安放膝上；戰鬥中的僧衣可沿既有圖更破舊，但不得更換人物或增加飾物。
- 三人被阿婆右手打到自身左臉，各只有一個灰色凹陷掌印。正面時掌印在畫面右側；轉頭後仍附著於同一側，不能為了讓讀者看見而移到右臉。
- 葉三千受擊後面朝地倒下，雙手仍在袖裡，接下一頁原地爬起；獨孤斷右手支撐右膝、左膝跪地；無葉僧維持浮坐。
- 採葉過場為正上方鳥瞰：三人正三角形朝中心，葉三千左下、獨孤斷右下均站直，無葉僧在上方浮坐。

## 植物與字體

- 九層塔採寫實草本形態：細實分枝莖、對生尖卵形葉、有葉脈、可有小型花穗；斷莖只有小面積實心斷面，不是竹管、木樁或粗空心圓筒。
- 旁白：粗黑正體字、白底細黑矩形框；一般對話：同類粗黑正體字、白底對話框。大喊可放大加重。
- 「夭壽喔！」與「啪！」：強烈黑色手寫筆勢；「萬葉無蹤」：既定白字黑描邊風刃字；結尾詩：既定書法字及黑白阿婆印章。
- 各字體按用途一致，不把所有字硬改為同一種。字保持大而易讀。
